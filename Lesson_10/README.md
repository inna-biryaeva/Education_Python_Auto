# Lesson 10: Создание отчётов в Allure Report
 
Данный проект содержит автотесты для веб-приложений (Калькулятор и Интернет-магазин SauceDemo). В проекте реализован паттерн **Page Object** для разделения логики тестов и элементов страниц, а также интегрирован фреймворк **Allure** для формирования подробных HTML-отчётов.


## Предварительные требования

Перед началом работы убедиться, что на компьютере установлены:
- **Python 3.xх** и настроено виртуальное окружение (`.venv`).
- **Allure Commandline** (в данном проекте используется путь: `C:\allure-2.46.2\bin\allure.bat`).
- **Git** для контроля версий.


## Структура проекта

```text

Пошаговая инструкция по запуску

Шаг 1. Открыть терминал в PyCharm и создать новую ветку и новую директорию.
Шаг 2. Установить зависимости: pip install selenium pytest allure-pytest.
Шаг 3. Запустить тесты: pytest --alluredir=allure-results
Шаг 4. Сформировать отчёт Allure для просмотра: C:\allure-2.46.2\bin\allure.bat generate allure-results -o allure-report.
Шаг 5. Открыть отчёт для просмотра: C:\allure-2.46.2\bin\allure.bat open allure-report.
